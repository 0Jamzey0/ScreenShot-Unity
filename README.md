# ScreenShot-Unity
This is a Simple C# script that allows you to take high Quality Screen Captures via unity's Engine itself (through its Camera' Render Texture Component) to avoid losing any visuals when using the traditional PicScr button

**_Features_**
* You can select target resoultion for the output image
* You can immediatley Capture a Shot at the Start of the playMode via the CaptureAtStart bool
* Change and modify the name of the Output Image and its format (Note : i dont recommend changing its format from PNG)
* Capture a Shot during any time of PlayMode by pressing 'P' (Can be changed to any button via Code)
